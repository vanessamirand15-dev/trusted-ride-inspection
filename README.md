# Trusted Ride Inspection

Trustferly: Independent Vehicle Inspection Platform

Build a modern, premium, responsive website called Trustferly, a platform connecting people who are considering buying a used vehicle with independent professional vehicle inspectors.

Important: Trustferly does NOT sell vehicles, list cars for sale, provide loans, or act as a dealership. Its purpose is to make private-party used-car transactions safer and more transparent through professional pre-purchase inspections.

1. Brand Identity and Color Palette

Use this exact palette:

Dark Navy #102A43: Navigation, headings, footer, brand identity

Trust Blue #2563EB: Primary buttons and booking actions

Verified Teal #0D9488: Inspection status, verification, success indicators

Off-White #F8FAFC: Background
